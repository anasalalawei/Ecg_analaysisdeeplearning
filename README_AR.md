# ECGFounder Offline Web — حزمة الموقع المحلي

## ما الموجود داخل الحزمة؟
- نموذجك المدرب `models/best_ecgfounder_ptbxl.pth` (مرفق داخل ZIP).
- تعريف معمارية ECGFounder Net1D المطابق لأسماء مفاتيح checkpoint، مبني على تنفيذ PKUDigitalHealth الرسمي.
- خادم FastAPI وواجهة ويب عربية بتصميم responsive.
- SQLite لحفظ سجل العمليات محليًا.
- رفع إشارات رقمية NPY/CSV وتشغيل النموذج فعليًا.
- رفع صورة ECG للمعاينة والحفظ المحلي، مع إظهار أن digitization غير موصول بعد.

## مهم جدًا بخصوص الصور
ECGFounder لا يستقبل صورة ورقية. يستقبل إشارة رقمية من 12 اشتقاقًا و5000 عينة لكل اشتقاق (10 ثوانٍ عند 500Hz). الحزمة لا تحتوي على خوارزمية موثوقة لتحويل صورة ورقية إلى 12-lead signal؛ لذلك لن تعرض تنبؤًا من صورة. هذا يمنع النتائج الوهمية. يدعم التطبيق حاليًا inference على CSV/NPY رقمي حقيقي.

## تشغيل Windows 11
1. فك ضغط `ECGFounder_Offline_Web.zip`.
2. يتطلب Python 3.11.
3. افتح PowerShell داخل مجلد المشروع.
4. نفّذ مرة واحدة مع اتصال إنترنت لتثبيت بيئة التشغيل:
   `Set-ExecutionPolicy -Scope Process Bypass`
   `./install_windows.ps1`
5. بعد تثبيت الحزم يمكن فصل الإنترنت وتشغيل:
   `start_windows.bat`
6. افتح `http://127.0.0.1:8000`.

بعد تثبيت الحزم، الموقع والمعالجة يعملان محليًا ولا يرسلان البيانات إلى الإنترنت. النسخة المضمنة تثبت PyTorch CPU. يمكن إعداد CUDA لاحقًا إذا كان جهاز Windows يحتوي NVIDIA GPU متوافقًا.

## صيغة ملفات الإشارة
- NPY: مصفوفة `(12,5000)` أو `(5000,12)`.
- CSV: 12 عمودًا × 5000 صفًا، أو العكس، بدون عمود زمن أو أسماء أعمدة نصية.
- يجب أن تكون القنوات مرتبة حسب ترتيب PTB-XL الأصلي: `I, II, III, aVR, aVL, aVF, V1, V2, V3, V4, V5, V6`.
- يجب أن تكون القيم بوحدات WFDB الفيزيائية المتوافقة مع PTB-XL قبل التطبيع. يطبق التطبيق نفس تطبيع التدريب: mean وstd واحدان على كامل مصفوفة 12×5000 لكل تسجيل، بالصيغة `(signal - signal.mean()) / (signal.std() + 1e-8)`. لا يضيف التطبيق مرشحات أو إعادة أخذ عينات.

## عتبات القرار
تستخدم الحزمة العتبات التي حُددت على validation في جلسة التدريب السابقة:
`[0.3048989, 0.1730635, 0.1963626, 0.1812232, 0.07899384]`

## اختبار النموذج
بعد تثبيت المتطلبات:
`python tests/smoke_test.py`

## الأمان والحدود
- التطبيق يستمع إلى `127.0.0.1` فقط، أي محليًا على الجهاز.
- ملفات الإدخال وسجل التحليلات تحفظ محليًا داخل `data/`.
- لا توجد خدمة سحابية أو API خارجي مطلوب أثناء التحليل.
- النتائج بحثية متعددة الملصقات وليست تشخيصًا طبيًا أو بديلًا عن طبيب.
- التحقق من الصورة إلى الإشارة يحتاج digitizer مستقلًا ومعايرة ورقية موثقة وتقييمًا على صور مرجعية قبل تفعيله.
